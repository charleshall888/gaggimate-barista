# Plan: switch-the-grind-map-and-user

## Overview

Flip the private-repo data layer from the Sette 270 to the DF64V + SSP Cast Lab Sweet V3 in two phases: (1) one atomic commit that history-preservingly `git mv`s the live `grind-map.md` to `grind-map-sette-270.archive.md` and creates a fresh grinder-agnostic 13-column DF64V map (Grind + a dedicated RPM column, no Grinder column) at the same path — so the main-repo symlink never spans a dangling window; (2) a separate commit repointing only the `user-setup.md` Grinder field. All writes land in the private data repo (`/Users/charlie.hall/Workspaces/gaggimate-barista-data`) via the symlink targets, committed with the CLAUDE.md `--git-dir/--work-tree` auto-commit form. Best-effort device telemetry capture runs first, non-blocking. No main-repo source files change — the only main-repo diff is this lifecycle's artifacts.

**Goal**: Snapshot recoverable telemetry (best-effort), then in ONE atomic commit archive the Sette map byte-identically and stand up a fresh DF64V `grind-map.md` (RPM column, zero data rows, configured-but-empty), pushed once.
